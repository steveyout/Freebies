# 🚀 FMHY Repository Directory (`data/`)

Welcome to the **FMHY Markdown Directory**. This directory contains the Markdown files for each major section of the FMHY Index.

## 📂 Repository Markdown Structure

- `data/streaming.md` - Movies, TV Shows, Anime, Live Sports & Media Indexers
- `data/adblocking.md` - Adblockers, DNS Shields, Link Bypassers & Privacy Extensions
- `data/software.md` - Free & Open Source Software, Utilities & Archivers
- `data/games.md` - Game Emulators, Preservation Tools & Launchers
- `data/ai-tools.md` - Local LLM Runners, Open Models & AI Workbenches

## ✍️ How to Add a New Site to the Index

To add a new site (for example, a movie or TV streaming site):
1. Open `data/streaming.md` (or the relevant `.md` file).
2. Add a new row under the appropriate table section:
```markdown
| **YourSite** | [yoursite.com](https://yoursite.com) | 1080p | ❌ Not Needed | Fast streaming, zero ads, multi-subtitles |
```
3. Or add a Callout box for top priority picks:
```markdown
> [!YOURSITE] **Featured Streaming Site**
> **YourSite** ([https://yoursite.com](https://yoursite.com)) offers 1080p movies with no ads.
```
4. Save the file or submit a pull request! The FMHY web application automatically parses Markdown files and updates the interactive UI cards and search index instantly.
